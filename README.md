# Pitkävetotulokset

Sivu näyttää viimeisen 14 päivän pelattujen otteluiden tulokset ja niiden 1X2-lopputuloksen. Sarjat ovat jääkiekon maaottelut (Euro Hockey Tour ym.), Liiga, Mestis, Suomi-sarja, SHL, NHL, NBA, Valioliiga, La Liga, Bundesliiga, Serie A, Ligue 1, Mestarien liiga, Eurooppa-liiga ja Konferenssiliiga.

Tulokset haetaan aina, kun sivu ladataan.
